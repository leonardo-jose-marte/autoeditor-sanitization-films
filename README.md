# 🎬 AutoEdit & Manim Video Pipeline

> Una herramienta open source creada por creadores y para creadores para automatizar la edición de videos largos, eliminar silencios y añadir motion graphics sin depender de costosos plugins privativos.

## 🤔 ¿Por qué este proyecto?

Editar videos largos (de 40 a 50 minutos) para plataformas educativas o de contenido técnico suele consumir horas valiosas en tareas repetitivas: cortar silencios, sincronizar cortes, buscar recursos visuales y armar animaciones. Las soluciones tradicionales en el ecosistema de Adobe dependen de licencias costosas o plugins de pago que no siempre están al alcance de todos.

Este proyecto nace con una misión clara: **automatizar el flujo de trabajo pesado mediante código y agentes**. Queremos que pases de perder 3 o 4 horas picando video en una línea de tiempo a invertir ese tiempo en lo que realmente importa: planificar mejor la información, diseñar mejores explicaciones y crear una comunidad sólida.

## 🚀 ¿Qué hace (o hará) este sistema?

* **Eliminación inteligente de silencios:** Detecta y recorta los baches y pausas vacías automáticamente para mantener un ritmo dinámico en el video.
* **Sintetización y ensamblaje:** Procesa los cortes del diálogo de forma automatizada.
* **Motion Graphics con Manim:** Integra animaciones matemáticas y visuales programáticas para ilustrar conceptos complejos directamente en el video.
* **Entorno asistido por agentes:** Un arnés de agentes automatiza la toma de decisiones técnicas y el encadenamiento de tareas durante el renderizado.

## 🛠️ Stack Tecnológico

* **Python:** Lenguaje base para la orquestación y el procesamiento lógico.
* **AutoEdit:** Para la gestión de cortes, transcripción y eliminación de silencios.
* **Manim:** Para la generación de gráficos en movimiento de alta calidad.
* **Agentes de IA:** Para automatizar el flujo y ahorrar fricción operativa.
